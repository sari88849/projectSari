# Frontend (Angular 21, Hebrew RTL)

```bash
npm install
npm start        # http://localhost:4200, /api is proxied to http://localhost:5080 (proxy.conf.json)
npx ng build     # production build
```

The structure and design notes are in [../docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md#11-frontend). Setup for the whole system is in the root [README](../README.md).
